# Patients

A patient can have a phone number without a name. The unknown-patient label is
for display only. Contact import must preserve existing names and must not use
unknown-caller labels as patient names.

Numbers without a country code are Indian. Contact matching must ignore display
punctuation.

Search with all of a contact's phone numbers: one contact can match several
patient records under different numbers.

See [persistence](persistence.md) for live patient summaries and cancellation rules.
