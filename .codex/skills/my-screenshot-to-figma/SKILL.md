- Aim for a full-fidelity, pixel-perfect design - except for things that are clearly not related to the app (e.g., icons of other apps and wallpaper in homescreen widget screenshots).
- Use Figma MCP, never Computer Use, desktop automation, or browser automation to operate Figma.
- Always work in the existing [Clinical Figma file](https://www.figma.com/design/SE5qfKLHQwGJvN20qSc89l). Its file key is `SE5qfKLHQwGJvN20qSc89l`.
- Use a device frame just like existing artboards in the file
- Use Apple's official iOS 27 UI Kit components already available in Figma wherever possible.
- Look up exact SF Symbol names from the code, instead of guessing from the screenshot
